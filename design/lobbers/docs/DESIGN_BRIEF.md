# Design a Complete UI/UX Mockup for a Multiplayer Artillery Game

Act as a senior game UI/UX designer, art director, and frontend game interface developer.

Design a visually stunning, modern browser-based multiplayer artillery game inspired by Gunbound, Worms, and classic cartoon tactical battle games.

The game supports up to 8 players per match (4v4).

Your task is to create a COMPLETE, HIGH-FIDELITY, INTERACTIVE FRONTEND MOCKUP that feels like a real, professionally released multiplayer game.

Do not create a generic SaaS dashboard. This must look and feel like an actual video game.

# 1. Overall Art Direction

Create a distinctive visual identity.

Visual inspiration:
- Gunbound's colorful artillery battles.
- Worms' playful cartoon characters.
- Modern indie multiplayer games.
- Polished gaming interfaces.
- Colorful sci-fi environments.

Art direction:
- Playful but visually sophisticated.
- Cartoon-style battle machines and characters.
- Rich, colorful environments.
- Expressive illustrations.
- Chunky and recognizable UI elements.
- Smooth animations.
- Strong visual hierarchy.
- Detailed game assets.

Avoid:
- Generic admin dashboard aesthetics.
- Excessive glassmorphism.
- Excessive gradients.
- Generic AI-generated landing page layouts.
- Oversized empty spaces.
- Excessively rounded cards everywhere.
- Emoji as substitutes for actual game illustrations.
- Generic stock photos.

Use custom-looking game illustrations, SVG assets, CSS artwork, and original visual elements.

# 2. Color System and Typography

Establish a consistent visual design system.

Suggested palette:
- Deep navy: #151B2B
- Dark background: #101522
- Warm off-white: #F5F1E8
- Team Red: #F45B55
- Team Blue: #4C9AFF
- Electric yellow: #FFD166
- Success green: #5ACB91

Use:
- Bold display typography for headings.
- Rounded, playful typography for game elements.
- Highly readable typography for statistics and controls.
- Monospaced numerals for timers, health, and ammunition.

Support a cohesive visual identity across every screen.

# 4. Multiplayer Lobby

Design a complete 8-player lobby.

Display two opposing teams.

TEAM RED:
- Four player slots.
- Player avatars or machine illustrations.
- Player names.
- Ready indicators.
- Host indicator.

TEAM BLUE:
- Four player slots.
- Same structure.

Empty slots should invite players to join.

Center area:
- Selected battlefield preview.
- Map name.
- Map description.
- Match settings.
- Player count (e.g. 6/8).

Bottom controls:
- Change Machine.
- Customize.
- Invite Friends.

Make the team separation visually obvious.

Show player connections and ready states through subtle animations.

# 6. Main Battlefield Interface

THIS IS THE MOST IMPORTANT SCREEN.

Design a full-screen landscape-oriented battlefield.

The battlefield should occupy approximately 75–85% of the visible screen.

Use a beautiful illustrated 2D side-view landscape with:
- Destructible hills.
- Mountains.
- Floating islands.
- Trees.
- Rocks.
- Background scenery.
- Atmospheric effects.
- Two opposing teams.

The battlefield must look like a playable game, not a static illustration.

### Top HUD

LEFT:
- Team Red information.
- Remaining players.
- Team health.

CENTER:
- Current turn indicator.
- Active player name.
- Turn countdown timer.

RIGHT:
- Team Blue information.
- Remaining players.
- Team health.

### Player information

Show compact health bars and character portraits.

Clearly distinguish:
- Living players.
- Eliminated players.
- Current player.
- Teammates.

Include:

# 15. Implementation Constraints

This is a FRONTEND-ONLY MOCKUP.

Do not implement:
- Real matchmaking.
- Actual WebSocket connections.
- Backend APIs.
- Database integration.
- Authentication infrastructure.
- Real multiplayer synchronization.

Use mock data and local frontend state.

However, structure components cleanly so real multiplayer functionality can be integrated later without rebuilding the UI.

Keep game rendering separate from the HUD and interface components.

# 16. Final Quality Requirements

The result must feel like a commercially released indie multiplayer game.

Prioritize:
1. Exceptional battlefield design.
2. Beautiful machine illustrations.
3. Professional game HUD.
4. Consistent visual identity.
5. Smooth interactions.
6. Complete screen coverage.
7. Responsive layouts.
8. Consistent spacing and typography.

Do not stop after designing the home screen.

Implement all the screens described above.

The battlefield must be the visual centerpiece and should receive the most design attention.

**Final deliverable:** A cohesive, high-fidelity, interactive browser game UI mockup that can be demonstrated as if the actual multiplayer game already exists.
